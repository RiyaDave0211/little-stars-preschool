# little-stars-preschool
Preschool Portal

📖 About The Project

Little Stars Preschool is a web-based preschool management portal designed to make preschool activities, student learning, attendance tracking, teacher management, and parent communication easier.

The platform provides separate experiences for students, teachers, and school administrators.

It combines educational activities with school management features in a colourful, interactive, and child-friendly interface.
